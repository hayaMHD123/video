# حكايا — استوديو فيديوهات تعليمية للأطفال

موقع محلي مبني بـ Next.js لتحويل وصف الحلقة إلى خطة مشاهد وبرومبتات صور، ثم تركيب الصور التي تنشئها بنفسك مع التعليق الصوتي والترجمة والموسيقى في فيديو MP4 بدقة 1080p. يمكنك بعد ذلك تنزيله أو ربط قناتك ورفعه إلى YouTube مباشرة. الواجهة عربية وتعمل على جهازك؛ لا تتطلب اشتراكاً مدفوعاً أو خدمة تصيير سحابية.

## تشغيل سريع

تحتاج إلى [Node.js 20.9 أو أحدث](https://nodejs.org/) ومتصفح حديث مثل Chrome أو Edge. افتح PowerShell داخل هذا المجلد وشغّل:

```powershell
npm install
npm run dev
```

افتح [http://127.0.0.1:3000](http://127.0.0.1:3000). لإيقاف الموقع اضغط `Ctrl+C` في نافذة PowerShell. بعد تعديل `.env.local` أعد تشغيل الموقع.

إذا أردت إنتاج نسخة مهيأة للتشغيل بدلاً من وضع التطوير:

```powershell
npm run build
npm run start
```

## طريقة إنتاج حلقة

1. اكتب وصف الحلقة والفئة العمرية والمدة والمقاس: أفقي ليوتيوب أو عمودي لـ Shorts.
2. راجع الخطة وبرومبت كل مشهد. تستطيع تعديل النصوص، المدد، ترتيب المشاهد، حركة الصورة والانتقال. انسخ البرومبتات وولّد الصور بالأداة التي تستخدمها أنت؛ الموقع لا يولّد الصور ولا يشترط خدمة صور مدفوعة.
3. ارفع صورة لكل مشهد. أضف ملف تعليق صوتي، وترجمة SRT، وموسيقى تملك حق استخدامها إذا أردت. يمكنك تعديل مدة المشاهد لتقارب طول التعليق.
4. شاهد المعاينة، ثم صدّر MP4 على جهازك. التصدير يتم داخل المتصفح دون رفع صورك أو صوتك إلى خادم تصيير.
5. للرفع المباشر، اربط قناة YouTube، راجع العنوان والوصف والوسوم والجمهور والخصوصية، وأضف صورة مصغّرة اختيارياً. يمكنك الرفع يدوياً بعد التصدير أو اختيار الرفع التلقائي بعد نجاحه.

يحفظ الموقع مسودة المشروع في **هذا المتصفح على هذا الجهاز**: نصوص الخطة في التخزين المحلي والملفات في IndexedDB. لا تعتمد عليه كنسخة احتياطية وحيدة؛ زر «تنزيل الخطة JSON» يحفظ النصوص، واحتفظ بالصور والصوت الأصلية لديك. إنشاء مشروع جديد يحذف مسودة المشروع وملفاته المحفوظة من المتصفح بعد تأكيدك.

## الذكاء الاصطناعي دون دفع

الموقع يعمل فوراً بقالب مسودة قابل للتعديل. لتحصل على خطة أكثر تخصيصاً، أضف مفتاح Gemini المجاني إذا كانت الخدمة متاحة في بلدك، أو شغّل Ollama محلياً على جهازك. ترتيب الاختيار: Gemini ثم Ollama ثم القالب. لا يوجد انتقال تلقائي لخدمة مدفوعة. الإعداد في [AI_SETUP.md](docs/AI_SETUP.md). وضع المفتاح في `.env.local`، وليس في صفحة الموقع، يحميه من الظهور للمتصفح.

بحسب [قائمة Google للمناطق المتاحة](https://ai.google.dev/gemini-api/docs/available-regions)، سوريا غير مدرجة حالياً؛ إن كنت تتصل من سوريا، استخدم Ollama أو المسودة القالبية. الحصص المجانية والبلدان المدعومة قد تتغير.

## ربط YouTube وحدوده

تفاصيل OAuth وإعداد القناة في [YOUTUBE_SETUP.md](docs/YOUTUBE_SETUP.md). يلزمك إنشاء بيانات OAuth بنفسك في Google Cloud؛ لا يمكن للموقع ربط قناتك دون موافقتك. يرفع الموقع الفيديو كـ «مخصّص للأطفال» افتراضياً، لكن راجع التصنيف والمحتوى قبل النشر. إعداد الرفع الحالي **محلي ولصانع محتوى واحد**، وليس آمناً كنشر عام متعدد المستخدمين دون إضافة نظام حسابات وتخزين رموز منفصل.

قد تجعل Google كل فيديو يُرفع عبر مشروع YouTube API جديد غير مدقّق **خاصاً**، حتى لو اخترت «عام». لذلك الرفع المباشر يعمل من الناحية التقنية لكنه لا يضمن الظهور فوراً للجمهور قبل [تدقيق مشروع API](https://developers.google.com/youtube/v3/guides/quota_and_compliance_audits). يبيّن الموقع الحالة التي أبلغ عنها YouTube. الصورة المصغّرة اختيارية؛ إذا فشل رفعها بعد نجاح الفيديو، يخبرك الموقع ويمكن إضافتها من YouTube Studio.

## ما الذي يجعل النتيجة احترافية؟

المحرر يوفّر 1080p، حركة لطيفة للصور، انتقالات، عناوين وترجمة عربية داخل الفيديو، ومزجاً هادئاً للموسيقى تحت التعليق. مستوى الحلقة النهائي يعتمد أيضاً على صور متناسقة للشخصية، تعليق صوتي واضح، توقيت مدروس، وتدقيق تربوي ولغوي بشري. استخدم صوراً وموسيقى تملك حق نشرها، وافحص الحلقة كاملة قبل رفعها للأطفال.

تستخدم النسخة الحالية [Remotion](https://www.remotion.dev/docs/license/faq) لتصيير الفيديو؛ رخصته مجانية للأفراد وللمنظمات حتى ثلاثة أشخاص وفق شروطه الحالية، حتى للاستخدام التجاري. إذا كبر الفريق، راجع شروط الرخصة قبل الاستمرار. لا تعد عبارة «مجاني» وعداً بثبات حصص Gemini/YouTube أو بتكلفة كهرباء/إنترنت صفرية.
